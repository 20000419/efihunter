# Worked example

`example/` should hold one SMM module's input pseudocode plus EFIhunter's output
(per-function verdicts, confidence scores, and reasoning traces).

IMPORTANT: do not redistribute proprietary vendor firmware or its full
decompilation. Ship either (a) a public/synthetic input, or (b) only the OUTPUT
artifacts (verdict JSON + reasoning traces) for a sample drawn from a public
advisory. The counterfactual baseline reasoning traces referenced in the paper
(Section 8) go here.
